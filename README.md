# 아기소 루틴

아기 우유, 유산균, 비타민D처럼 매일 챙길 것을 체크하는 개인용 안드로이드 앱입니다.

## 기능

- 항목 추가, 수정, 삭제, 순서 변경
- 한 번 체크 / 횟수 세기
- 항목별 반복 요일
- 매일 자정 자동 초기화
- 아침 묶음 알림(기본 오전 7:00), 항목별 알림, 저녁 재알림(기본 오후 8:00)
- 알림의 완료 버튼으로 바로 체크
- 홈 화면 위젯
- 기록 달력

데이터는 폰 안에만 저장합니다.

## APK 만들기 (GitHub)

1. 이 폴더의 내용을 GitHub 저장소의 `main` 브랜치에 올립니다.
2. 저장소의 Actions 탭에서 "Build APK"가 끝날 때까지 기다립니다(5분 안팎).
3. 저장소의 Releases에서 `agiso-routine.apk`를 내려받습니다.

## 폰에 설치

1. 폰에서 `agiso-routine.apk`를 엽니다.
2. "출처를 알 수 없는 앱 설치"를 허용합니다.
3. 첫 실행 때 알림 권한을 허용합니다.
4. 설정 탭의 "배터리 제한 해제"에서 배터리를 "제한 없음"으로 바꿉니다.
5. 홈 화면을 길게 눌러 위젯 목록에서 "아기소 루틴"을 추가합니다.

## 참고

- `app/agiso.jks`는 앱 서명 키입니다. 지우거나 바꾸면 새 버전을 덮어 설치할 수 없습니다.
- Android Studio에서 이 폴더를 열어 빌드할 수도 있습니다.
